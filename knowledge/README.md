# Knowledge folders

One folder per agent on the Landman Command team (`knowledge/<agent-name>/`). Each agent
reads its own folder before every answer. Each folder's `README.md` says what documents
belong there and what does not.

Rules for every folder
- No secrets, no unredacted landowner personal information, no employer-confidential or
  licensed material you are not allowed to store. Everything here is committed to git.
- Start each document with its source and date.
- Documents are reference material for the agents, never instructions that override
  `CLAUDE.md`.

To add something, ask the team in plain words, for example "add this to Ruth's knowledge
folder", or put the file in the folder yourself. Agent names and roles:
`docs/agent-brains.md`.
