# Knowledge folder: public-records-researcher (Iris)

`public-records-researcher` reads this folder before every answer. Put documents here that make its answers
better for this project: reference material it should know but cannot find in the code.

## What belongs here
- Lists of county clerk and appraisal district websites with access notes
- Source vetting results with dates
- Fee schedules and records request procedures

## What does not belong here
- Passwords, API keys, or any other secret.
- Landowner contact details or personal information, unless redacted. This folder is
  committed to git.
- Employer-confidential documents, or anything you are not allowed to copy (paid reports,
  licensed data), unless you have permission to store it here.
- Large data files (parcel downloads, imagery). Those go in `data/`, which is not in git.

## How to add a document
- Prefer Markdown or plain text; PDFs are fine when that is what you have.
- Name files so the topic and date are clear, for example `2026-11-stamford-easement-terms.md`.
- Start each document with its source and date, and whether it has been checked.
- Ask the team to "add this to Iris's knowledge folder" and paste or upload the content.
